## 🚀 Getting Started

### 1. Development Mode
Run the local development server:
```bash
npm run dev
```

### 2. Production Build
Build optimized, tree-shaken, code-split production bundles:
```bash
npm run build
```

### 3. Production Preview
Preview the production build locally:
```bash
npm run preview
```
